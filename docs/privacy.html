Privacy Policy – BookScout

BookScout is an open-source application that allows users to discover, search for, and manage reading lists and personal book collections.

Third-Party Services

BookScout may use third-party services to fetch book metadata and handle cloud storage:

  • Book Data APIs (such as Google Books / Open Library): Used to retrieve book metadata, covers, summaries, and authors.

Open Source

BookScout is fully open source. You can inspect, contribute to, or fork the source code at: GitHub Repository.

Contact

If you have any questions or concerns regarding privacy, please open an issue on the GitHub repository or contact the maintainers directly.
