# BookScout

BookScout is a book tracking and reading management app built with Flutter.

## Key Features

- **Reading Management**: Keep track of books to read, currently reading,
  and finished/rated books.
- **Search & Discover**: Find books, authors, and essential details.
- **Modern & Clean UI**: Intuitive interface with light and dark mode support.
- **Cross-Platform**: Built for mobile and multi-platform support.
